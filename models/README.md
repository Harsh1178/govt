# Models Directory

This directory stores offline GGUF language models used by JanConnect for offline departmental classification and complaint clustering.

### Recommended Model:
- **Qwen2.5-1.5B-Instruct-GGUF (Q4_K_M)**
- Download URL: [HuggingFace - Qwen2.5-1.5B-Instruct-GGUF](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf)
- Save file as: `models/qwen2.5-1.5b-instruct-q4_k_m.gguf`

*(Note: Model files exceeding 100MB are excluded from Git via `.gitignore`)*
